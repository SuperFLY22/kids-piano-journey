# Kids Piano Journey - Image Assets Guide

웹 제미나이(Imagen / NanoBanana)에서 생성한 이미지를 아래 파일명 규격에 맞추어 해당 폴더에 저장합니다.

## 디렉터리 및 권장 파일명

```text
public/images/
├── app_icon/
│   └── app_icon.png           # 1:1 정방형 앱 아이콘 (1024x1024)
├── splash/
│   └── splash_bg.png          # 16:9 가로 시작/스플래시 화면 (1920x1080)
├── backgrounds/
│   ├── bg_song_mode.png       # 16:9 동요 비행기 리듬게임 배경 (구름/하늘/비행기)
│   ├── bg_tutorial_mode.png   # 16:9 5손가락 튜토리얼 배경 (아기자기한 음악 방)
│   └── bg_free_mode.png       # 16:9 자유 연주 모드 배경 (환상적인 무지개 은하수)
├── effects/
│   ├── trophy_reward.png      # 1:1 투명배경(PNG) 튜토리얼 올클리어 황금 트로피
│   ├── stars_3.png            # 1:1 투명배경(PNG) [3성/마스터] 별 3개 & 리본 엠블럼
│   ├── stars_2.png            # 1:1 투명배경(PNG) [2성/참잘했어요] 별 2개 엠블럼
│   ├── stars_1.png            # 1:1 투명배경(PNG) [1성/완주성공] 별 1개 & 새싹 엠블럼
│   └── combo_firework.png     # 1:1 투명배경(PNG) 팡파르 폭죽 & 음표 파티클
└── characters/
    ├── mascot_guide.png       # 1:1 투명배경(PNG) 귀여운 아기 동물 피아니스트 마스코트
    └── hand_guide_mascot.png  # 1:1 투명배경(PNG) 손가락 힌트 요정 캐릭터
```
